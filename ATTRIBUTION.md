# Icon attribution

The technology-logo paths embedded by `scripts/generate_profile.py` are from [Simple Icons](https://simpleicons.org/) under CC0-1.0, except where noted below.

- Java is represented by the OpenJDK icon.
- JWT, Spring Boot, PostgreSQL, and Git use their corresponding Simple Icons entries.
